## FocusApp 0.1.1

Esta versión añade el actualizador de FocusApp.

- Consulta la última release estable de GitHub al arrancar y una vez al día mientras la app está abierta.
- Muestra un punto en el icono de la barra de menús cuando hay una versión nueva.
- En **Ajustes → Actualizaciones** puedes buscar una versión o descargar el DMG. FocusApp verifica su SHA-256 antes de abrirlo.

Si usas la **0.1.0 pública**, descarga este DMG e instala **0.1.1** para recibir avisos de las siguientes versiones. Requiere **macOS 14 o posterior** e incluye Apple Silicon e Intel. El instalador lleva firma ad hoc y carece de notarización. Consulta las [instrucciones de instalación](https://github.com/JuanCarlosAcostaPeraba/focusapp#descargar-e-instalar) si macOS bloquea el primer arranque.

## English

FocusApp now checks GitHub for stable updates, marks the menu bar icon when one is available, and downloads and verifies the DMG from **Ajustes → Actualizaciones**. If you use the public 0.1.0 build, install this DMG to receive future update notices. See the [English installation guide](https://github.com/JuanCarlosAcostaPeraba/focusapp/blob/main/README.en.md).
