## FocusApp 0.1.4

- Corrige un fallo que dejaba legible el texto de las ventanas del fondo incluso con el desenfoque al máximo.
- Simplifica Ajustes con dos preajustes, **Suave** (25 % de desenfoque) e **Intenso** (55 %). Ambos aplican un 50 % de grano.
- Retira el monocromo, el tinte y el control de oscurecimiento. Los valores de desenfoque y grano guardados se conservan. El antiguo preajuste **Solo tinte** pasa a **Suave**.

Desde la **0.1.3**, abre **Ajustes → Actualizaciones** para descargar el DMG. Requiere **macOS 14 o posterior** e incluye Apple Silicon e Intel. El instalador lleva firma ad hoc y carece de notarización. Si macOS bloquea el primer arranque, consulta las [instrucciones de instalación](https://github.com/JuanCarlosAcostaPeraba/focusapp#descargar-e-instalar).

## English

- Fixes an issue that left background window text readable even at maximum blur.
- Settings offers **Suave** (25% blur) and **Intenso** (55% blur), both with 50% grain.
- Removes monochrome, tint and dimming controls. Existing blur and grain values are preserved. Accounts using the old tint-only settings start with **Suave**.

From **0.1.3**, open **Ajustes → Actualizaciones** to download the DMG. It requires **macOS 14 or later** and supports Apple Silicon and Intel. See the [English installation guide](https://github.com/JuanCarlosAcostaPeraba/focusapp/blob/main/README.en.md).
